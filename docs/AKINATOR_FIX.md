# Counted-attribute recovery and interface revision

The reported four-filled-triangle failure had two causes: enumeration admitted only count two for a shape-and-fill selector, and uniformly random scenes almost never exhibited four matching objects. Negative-only answers therefore could not identify the intended program.

The grammar now enumerates exact and at-least counts zero through six over reusable shape/fill selectors, plus total-count-and-universal-attribute compositions. Queries include homogeneous count witnesses, irrelevant distractors, higher/lower counts, and mixed attribute groups. The hypothesis engine caches selector counts and AST child predictions, so broader coverage remains practical. Query votes are grouped by observed behavior to avoid over-weighting many spellings of the same rule; priors give counted attribute combinations equal treatment with primitive counts.

Specific rules accepting only one narrow type of drawing can require a long negative search under a single-image protocol. After six negatives without a positive, the active selector may ask an explicitly labeled ANY query over up to four independent drawings. A positive union answer does **not** label all its members: each stays available for individual follow-ups. Undo restores the complete union and prior version space. This behavior has a dedicated regression test. The evaluator itself remains hard symbolic.

The regression covers four seeds and three distinct meanings: exactly four matching filled triangles (other objects allowed), at least four matching filled triangles, and exactly four objects all of which are filled triangles. Results, complete programs, survivor traces, question counts, individual drawings inspected, and batch counts are recorded in `data/regressions/akinator_counts.json`. Oracle-driven tests are not a human user study.

The UI now uses a black/white palette with Klein blue (#002FA7), monospace type, square controls and compact state. Bongard is Input → Review drawings → Infer rule. Its two groups appear once in aligned contact sheets; individual attributes and evidence are inspected separately. Model/search parameters, alternatives and raw JSON are collapsed. All support drawings are used by default; held-out evaluation is an explicit option. The prior experiment report is retained as a historical result rather than relabeled as a measurement of the new search/protocol.
