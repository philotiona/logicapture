# Neuro-symbolic perception and reasoning

## Structural redesign

The default Bongard pipeline now follows the user's later correction about arbitrary strokes and arrow flow. See [BONGARD_REDESIGN.md](BONGARD_REDESIGN.md). The earlier two geometric pipelines described below are retained ablations. The default reads ink components as paths and closed regions, retains actual contours and graph topology, and compares arrow directions along a shared curve. Open strokes bypass the closed-set shape CNN. Optional neural region predictions retain distributions but cannot overwrite contradictory closure/shape measurements. `Rule.assess` preserves unavailable evidence with a third truth value; this is hard reasoning with abstention, not the planned probabilistic evaluator.

This document updates the original project brief according to the user's later architecture requirements. Existing scene, DSL, search, renderer, Akinator and deterministic OpenCV modules are retained. Neural perception was added only after the symbolic foundation and both UI flows had passing tests.

## Data flow

```text
Uploaded page or group images
  → OpenCV normalization and panel detection
  → OpenCV contour hierarchy and isolated individual ink regions
  → one of two attribute paths:
       1. deterministic contour shape / hole-based fill baseline
       2. small TensorFlow CNN with shape and fill softmax heads
  → VisualObject: measured geometry + hard attributes + optional probabilities
  → argmax hard symbolic evaluator
  → ranked executable rule + evidence + validated new drawings
```

The object CNN never receives Group A/B labels, the whole Bongard page, or the secret rule. It sees one isolated grayscale component in a padded 48×48 crop. For nested objects, a contour's direct hole interiors (including ink belonging to enclosed objects) are excluded from its region; the enclosed component receives a separate region.

The default UI neural policy sends objects below an OpenCV confidence trigger, or ambiguous hole-ratio detections, to the CNN. The trigger is exposed. A classify-all option makes the full comparison reproducible; the synthetic experiment uses this policy and records it. The model outputs distributions over circle/triangle/quadrilateral/polygon and outline/filled. Hard attributes are the argmax, and both complete distributions are retained. Color and geometric relations remain measured through OpenCV/geometric calculations.

## Scene contract

`VisualObject` includes `shape`, `filled`, measured geometry/contour, `shape_probabilities`, `fill_probabilities`, `confidence`, and `attribute_source`. Optional distributions must be finite, nonnegative, supported-label distributions summing to one. They survive JSON export/import. Objects generated by Akinator use known attributes and have no perception distributions; Akinator never routes its own drawings through CV or CNN.

The existing `Predicate` and `Rule` evaluators read hard attributes only. This preserves exact Boolean semantics, version-space elimination, generation checks and the existing tests. A future `soft_evaluate` API can consume the same distributions without silently changing hard semantics. It will need documented conjunction/disjunction/quantifier semantics, treatment of correlated attributes and uncertain object existence, calibrated distributions, and tests before being considered an implemented fourth system. No soft-symbolic numbers are presented today.

## Compared systems

| System | Status |
|---|---|
| Whole-image TensorFlow prototypical CNN | Implemented, trained, measured; predicts classes without an executable concept explanation |
| OpenCV + hard symbolic reasoning | Implemented, retained baseline |
| OpenCV segmentation + neural attributes + hard symbolic reasoning | Implemented, selectable and measured |
| Neural perception + soft/probabilistic symbolic reasoning | Planned; scene probability contract implemented, evaluator pending |

The object CNN is trained from independently labeled synthetic isolated objects. Its test set uses a different seed. These tests measure attribute recognition under synthetic rendering variation, not robustness to human drawings. Softmax outputs are not calibrated confidence estimates. The polygon class uses regular pentagons and does not establish general topology recognition. A CNN cannot repair merged or missing objects produced by segmentation; those remain measurable perception failures.

## Reproduce

```powershell
.\.venv\Scripts\python.exe -m src.vision.attribute_cnn --epochs 12 --per-class 90
.\.venv\Scripts\python.exe -m src.evaluation.experiments --episodes 10 --neural --train-episodes 500 --attributes-model data/models/attributes.keras
```

The saved model is `data/models/attributes.keras`, its validation report is `training.json`, and cross-system problems/results are under `data/pilot` for the supplied small run. A new run defaults to `outputs/evaluation` and does not overwrite the included pilot.
